# Web interface

A browser UI for uploading a FASTA alignment and getting a Newick tree back.
Everything runs locally in the browser — no server-side computation.

## Run locally

```sh
make web
cd web
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

## Features

- **Upload** a FASTA file via file picker or drag-and-drop, or **paste** a FASTA alignment directly
- **Auto-detect** nucleotide vs protein sequences (overridable)
- FastTree options: `-gtr`, `-gamma`, `-nosupport`, `-fastest`
- Displays the raw **Newick** string (copy to clipboard or download as `.nwk`)
- Renders a simple **rectangular tree preview** as SVG

The WASM module is loaded from `pkg_web/`, generated by `make web`.
